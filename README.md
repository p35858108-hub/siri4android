# Siri (asistente Android · isla de cristal líquido + Gemini web)

* Abre la carpeta en Android Studio (Koala o superior), sincroniza Gradle y ejecuta en el POCO X6 5G.
* `app/src/main/assets/web/` se puede probar solo en un navegador de escritorio (abre index.html; usa respuestas simuladas).
* Selectores de Gemini: `app/src/main/assets/gemini_bridge.js` (bloque CFG).
* URL del motor: `Engine.URL` en `Engine.kt`.
* La interfaz deriva de neeldedkawala/ios-siri-animation (MIT, © 2026 Neel Dedkawala). Conserva el aviso de licencia.
